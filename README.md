# NEON//CONTRATOS

Sistema inspirado no universo Cyberpunk 2077 para gerenciamento de contratos e personagens de Night City.

## Tecnologias

- Python
- Django
- PostgreSQL
- HTML
- CSS

## Banco de Dados

PostgreSQL (Equipe 05)

## Funcionalidades

- Cadastro de personagens
- Cadastro de contratos
- Consulta de contratos
- Sistema de autenticação
- Integração com PostgreSQL
